What I Do Best

Repetitive tasks drive me nuts—so I automate them.

One of my favorite projects involved eliminating a bottleneck where analysts spent hours pulling reports and manually creating work items in Azure DevOps. Instead of accepting the tedious process, I built a Power Apps gallery, embedded it directly into a Power BI report in place of a static table, and connected it to Azure DevOps. This allowed end-users to create work items with a single click—right from within Power BI, turning insights into action instantly.

By leveraging Power Automate, SQL, and API integrations, I ensure that workflows run smoothly, systems talk to each other, and teams spend less time on manual work and more time on high-value tasks. If there's a process that's slowing things down, I find a way to automate, optimize, and simplify.
